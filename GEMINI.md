# Project: Trellone (Trello Clone)

## Tech Stack
- **Framework**: SvelteKit
- **Runtime**: Node.js / Bun
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Database**: SQLite (via Prisma)
- **Key Libraries**:
  - `prisma`: ORM
  - `svelte-dnd-action`: Drag and Drop
  - `lucide-svelte`: Icons
  - `zod`: Validation
  - `bcryptjs`: Password hashing

## Current Status
- **Phase**: Initialization / Auth Implementation
- **Version**: 0.0.2
